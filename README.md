Trabajo practico: Simon says
Empenzando de la base: https://www.youtube.com/watch?v=YE8gB-nhQMk

Reglas:
- Codigo en ingles o español
- Uso de una sola nomenclatura
- Hacer commits describiendo el proceso
- Archivos, imagenes, CSS y JS deben estar en carpetas
- Carpetas deben tener nomeclatura
- Uso del .gitignore
- No usar <"br">
- Referencias al JS deben estar al final del elemento <"body"> o <"head">
- Indentacion
- NO lineas en blanco
- Comentarios utiles
- Uso Flexbox
- Utilizar Medidas constantes
- Selectores de ID (#)
- MEDIA deben estar al final del codigo
- "Use strict"
- usar === y !==

Lista de requisitos:
"X" indica no terminado, "Y" es terminado
---------------------------------------------------
- X Correcion de codigo para que quede prolijo
- X Estetica basica, para un usuario
- X Capacidad de recordar nombres y puntaje (nombre minimo 3 letras)
- X Agregar mas puntaje cada vez se precione la luz correcta
- X Fallo, mostrar modal y un boton para reiniciar
- X Crear Pagina extra de contancto.
- X En la pagina Formulario, Usuario, Email y mensaje para enviar con la herramienta predeterminada?
- X Validaciones del Formulario de contacto, Mensaje minimo de 5 caracteres
- X Link del Repositorio del Juego (github), en una nueva pestaña
